01

게시물 링크 복사

사진만 추출

03

ZIP 파일로 보관

게시물별 폴더가 포함된 압축 파일을 기기에 저장합니다.

서버 연결 설정GitHub Pages 배포 시 필요 ⌄

Render 하나로 배포했다면 비워두세요. GitHub Pages라면 Render 주소를 입력하고 저장해야 합니다.

접근 키는 이 브라우저에만 저장됩니다. GitHub 소스 코드에는 포함되지 않습니다.

비공개 게시물 및 로그인 필요 게시물은 지원하지 않습니다. 인스타그램에 업로드된 뒤 서버에서 제공되는 화질이므로 업로드 전 원본과 다를 수 있습니다. 저장한 사진은 본인에게 권리가 있거나 허락받은 범위에서 사용하세요.
